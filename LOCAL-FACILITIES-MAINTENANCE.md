# Map 02: local facility search and exterior photographs

The existing nationwide static search remains available. Enter, category selection or the small-facility button also requests OpenPOI API. Selecting Search this area makes a fresh request for the visible bounding box. Moving the map alone makes no external request. Requests time out after ten seconds; cancelled or superseded results cannot reopen the list. Existing results remain usable when the external service fails.

Exact category choices use `/v1/search` with up to 200 results. Facility names and combined words use `/v1/suggest` (up to 20, full fields), which performs AND matching, relevance ranking and kana normalization. The name-search nationwide bounding box is 122,20,154,46, with the existing Japan boundary applied to every returned coordinate. Area searches discard the provider's automatic nationwide fallback. Results are leading candidates, not a complete nationwide inventory. Sources: https://api.openpoiapi.com/openapi.json and https://docs.openpoiapi.com/ (checked 2026-10-02).

Locations, addresses, coordinate precision, attribution and licences come from the response. Same names within 35 metres are deduplicated; separate branches remain distinct. OpenPOI sources are linked in the result list, map attribution and facility detail. Source licence conditions: https://openpoiapi.com/attribution.html . Search is fetched directly through the provider's public CORS endpoint; there is no API key or paid Google call.

The photo panel can load an explicit OSM Commons file, or a Wikidata photograph only after exact label/alias and Earth coordinates within 100 metres agree. Approximate OpenPOI locations do not start this lookup. Commons image metadata must confirm a supported free licence and a Commons source page; artist, licence and source are displayed as text and a link. A changed or closed panel invalidates late photo responses. No nearby or generic keyword photograph is substituted. Some small shops have no such public photograph and retain the explicitly labelled GSI aerial fallback.

For every facility, exterior controls open Google Maps business photos, Street View near the coordinates, or an exterior image search in a separate tab. Names and addresses qualify the business search. These are external links, not imported Google images. Photo availability, branch identity, opening status and capture dates still need checking. Maps URLs require no API key: https://developers.google.com/maps/documentation/urls/get-started . Google Places photo import was not enabled: https://developers.google.com/maps/documentation/places/web-service/policies .

Validation: `node scripts/build.cjs`; `node --test tests/place-media.test.cjs`. Browser checks use the actual public OpenPOI API, not a mocked provider. No external API response is bundled with the static release.
