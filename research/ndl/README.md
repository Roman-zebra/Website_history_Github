# 公開書籍によるスポット説明の改稿

対象は `data/places-world.json` の19件、`data/liminal.json` の26件、`data/landmarks.json` の34件、`data/regional-landmarks-v1.json` の92件、計171レコード。重複する場所は同一の調査結果を使う。最初に日本語本文を確定し、英語・韓国語・中国語（簡体字・繁体字）へ展開する。

## 採用基準

1. 国立国会図書館サーチで書誌を特定し、リンク先の**本文をログインなしで実際に開く**。「インターネットで読める」は個人送信を含むため、表示だけで採用しない。
2. 書籍の記述をそのまま転載せず、どのコマ・ページで何を確認したかを短い調査メモに記録して、自分の言葉で説明する。書籍の発行年と、描いている時代を本文でも区別する。
3. 近年の施設、現行の公開状況・安全規則は自治体・管理者などの公式資料で補い、確認日を残す。歴史資料から現在の営業・立入可否を推測しない。
4. 数値、最古・日本一・世界一、戦時労働など争いのある主張は、一次資料や公的機関の資料でも確かめ、断定の範囲を記す。出典が見つからない新しい事実は追加しない。
5. NDLの画像・PDFそのものは原則として複製せず、書誌・閲覧URL・ページ位置・独自の調査メモをGitHubに保存する。権利処理の必要な画像をリポジトリに混ぜない。

`spot-inventory.csv` は171レコードの作業台帳。`sources.json` は公開本文を確認した書籍と、現行情報を補う公式資料の出典台帳。公式資料のURLを記録しても、その資料が書籍であるという意味ではない。原稿とサイトのデータは同じブランチで管理する。

音声台本は `scripts/lab-3d/podcast/podcast_ja.json`、公開するMP3と時刻付き字幕は `3d/audio/` に置く。音声合成の行ごとのキャッシュとビルド途中のファイルは再生成できるためGitHubへ入れない。書籍の画像や全文も複製しない。
