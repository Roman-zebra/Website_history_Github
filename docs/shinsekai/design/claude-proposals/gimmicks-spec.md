## 2. 白塔の水と光
- **綾糸の瀧**：白塔の脚から**四方に**滝が落ち、しぶきに虹。落ちた水は下の**白雨亭（下層の休憩所）の屋根に当たり、軒から玉すだれのように垂れる**（B003）。→ 水の板＋しぶきの粒＋軒先の細い水の線。
- **夜光の瀧**：夜は滝に**五彩の電光**（P001・B003）。色はゆっくり切り替え（1色あたり数秒、推定）。
- **真澄の池**：滝の下の**扇形の池**。滝の水で**渦の模様**。夜は**池の底から光**（B003）。
- 築山：花のトンネルをくぐって山の上へ。中層に休憩所「白露台」。

## 3. 塔
- エレベーター：**屋上庭園（50尺）から頂部まで**（開業期）。地上からは1938年以後なので、年代の切替でだけ出す（S7・S8）。
- 展望台：2段の回廊。眺めは六甲・生駒・金剛、晴れれば淡路島（S1）。
- 夜の電飾：輪郭の点の列、約3万個（S5、1出典）。常時点灯を基本に。

## 4. 園の乗り物と建物
- **サークリングウエーブ**：傾いた円形の枠に座席が並び、回りながら上下に波打つ（写真 V004 3:53–4:07）。回転はゆっくり。
- **音楽堂**：園の中央の八角形（B003）。演奏の音だけ流す（保護期間の切れた行進曲など）。
  - 注意：B003（1934年の本）は「欄干を**大阪市歌**の楽譜で飾る」と書く。今の大阪市歌は1921年（大正10年）制定だが、**1903年（明治36年）に作られた前の大阪市歌がある**（Wikisource「大阪市歌 (1903年)」）ので、1912年の開業時に楽譜の飾りがあっても矛盾しない。飾りに使うなら**1903年版の楽譜**（保護期間満了の見込み。Codex が権利を確認）。
- **一銭館**：60余りの**自動機械**（1銭で動く自動人形や仕掛け）。遊びの候補：硬貨を入れると小さな仕掛けが動く（人形は人の姿なので、動物や乗り物・からくりの仕掛けにする）。
- **水禽舎**（60余坪、300余羽）・**孔雀舎**・**モンキーホール**：人も動物も出さない方針なら、空の檻・池と**鳴き声の音だけ**。
- **不思議館**（からくり劇）・**美人探検館**（舞台と映像の組み合わせ）・**埃及館**：中身は架空の仕掛けで（人は出さない）。
- **スケーティングホール**：縞の屋根の室内リンク。ローラースケートの音。

## 5. 街
- **市電**：恵美須町の交差点（1914年の写真C に線路と架線）。車両の形は1912年のものを別に確かめる（V001・V004 の車両は後年）。
- **小旗の綱**：塔の頂から放射状、通りの上にも。風で揺れる。
- **装飾街灯**：多腕の柱に白い玉の灯り。夜に点灯。
- 開業の**緑門**（恵美須通の入口）：開業の日の限定の飾り。
