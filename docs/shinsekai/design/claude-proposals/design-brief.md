# デザインの手引き：1912年夏、開業したばかりの新世界とルナパーク（Claude、2026-09-30 11:30、案 v1）

M2（形）・M3（無料エリア）・M4（本編）の見た目の審査の基準。根拠は `claude-out\research\` の facts.md・photo-directions.md・tower-study-review.md・video-index.md。**推定**と書いた所は、考証モードで「推定」と表示する対象。

## 1. 一番の狙い（ひとことで）
**「電気の光が珍しかった時代の、夏の夕暮れから夜へ」**。昼は白く明るい洋風の街と、霞の向こうに立つ鉄の塔。夜は、塔と建物の輪郭が電球の点の列で浮かび、白塔の滝が五色に光る。人はいないのに、たった今まで賑わっていた気配（揺れる小旗、音楽堂の楽譜、回る乗り物）が残っている。

## 2. 時と天気
- 基本の日付：**1912年7月3日（開業日）前後の夏**。日の入りは19時15分ごろ（大阪）。夕の見せ場は 18:45〜19:45。
- 空：夏の薄い霞。「煙の都」なので、遠景（生駒の山並み・市街）は**青みがかった灰色に溶ける**。遠くほど彩度を落とす。
- 雨の日：濡れた土の道（舗装は石ではなく**土・砂利**が中心と推定）に街灯と電飾が映る。
- 季節の飾り：開業の祝いの**小旗の綱**（塔の頂から放射状、通りの上）と、恵美須通の入口の**緑の葉で覆った門（緑門）「祝開業」**（期間限定の飾りとして扱う）。

## 3. 光
| 時刻 | 太陽 | 人工の光 | 空気 |
|---|---|---|---|
| 昼 | 高い夏の日差し、影は短く濃い | 無し | 霞は薄い。白い土台が眩しく、鉄骨は暗い線 |
| 夕 | 低い西日、長い影（塔の影が街を横切る） | 18:50ごろから電飾が点き始める演出 | 霞が橙に染まる |
| 夜 | – | 塔・土台・園の建物の**輪郭を電球の点の列**でなぞる。白塔の滝に**五彩の電光**、真澄の池は**底から光る**。通りは装飾街灯（多腕の柱に白い玉） | 光のにじみ（ブルーム）は強め、霧に光の筋 |
- 電球の色：1912年は炭素線・初期のタングステン電球で**かなり暖かい色（2000〜2400K 相当）**、明るさは今の電球より弱い（**推定**）。今の LED のような白は使わない。
- 電飾は**点の列**であって、線状のネオンではない（ネオンは日本では1920年代後半から）。
- 「五彩」の色：赤・青・緑・黄・白の順に切り替える案（色の組み合わせと順は**推定**）。
- 点滅：当時の電飾の点滅の記録は未確認。基本は**常時点灯**、滝と池だけゆっくり色が変わる、を勧める。

## 4. 色（詳細は colors-proposal.json）
- 土台（凱旋門風）：**明るい生成りの漆喰・石積風**。白すぎず、少し黄み（**推定**）。
- 塔の鉄骨：暗い灰色〜黒に近い色（白黒写真で空より暗い）。塗装の色は不明＝**推定**。
- 白塔：**白**（「白く塗った娯楽館だから白塔」＝斎藤 1985）。
- 客車：屋根は**多色の縦縞の日よけ**（縁が波形）、車体は淡い色に花の絵（当時の手彩色の絵葉書。**推定**）。
- 洋風の建物：白〜淡い灰の壁、屋根はスレートや銅板の暗い色、ドームは暗い金属色（**推定**）。
- 和風の街並み（外側の通り）：黒い瓦、焼杉や漆喰の壁、暖簾と幟（文字は架空）。

## 7. やってはいけないこと
- 人・群衆・人の影を出さない。像も人の姿のものは避ける（正門の勝利の女神の像は扱いを相談）。
- 公開名や看板に「通天閣」を使わない。ビリケン、実在の会社の広告・商標（歯磨き・化粧品など）を出さない。塔の名前の額は無地か架空の文字。
- 2代目の塔（1956年〜）の形や、今の新世界の派手な看板を混ぜない。
- 1913年以後の施設（ラジウム温泉など）を1912年の場面に置かない（年代の切替で出す）。
- 今の LED のような白い光、ネオン管、アスファルトの黒い舗装。
