# Contemporary Luna Park program: museum preview and topology

The [Osaka Museum of History's 2012 exhibition page](https://www.osakamushis.jp/news/2012/tenjigae/120523.html) publishes a **350 × 252 pixel preview** of the reverse side of a Taisho-period `ルナパークプログラム` with a bird's-eye map. The museum owns the copy. This is likely the same kind of original program listed by Osaka Prefectural Library as `枚-282`, but object identity has **not** been established. The image's date within the Taisho period and reuse permission are unspecified. The museum page is copyrighted; study its geometry and factual description only. No museum image was copied into Git or the product. Ledger S029.

The preview confirms a bird's-eye drawing with the first tower at the park entrance/edge, a second upright White Tower farther inside, a connecting ropeway, and numerous built attractions. The museum's own description names **Circling Wave**, theatres and film houses as dense components of the park. At 350 pixels across, facility labels, scale and building footprints cannot be read reliably. The drawing is pictorial, not a survey. Do not digitize its pixels as metre coordinates.

The same page describes a separate three-panel period postcard: from its White Tower view, the **music hall is in front of White Tower**, the **Circling Wave is to its left in the image**, and the **Mystery Hall farther along**. This is a useful *image-space* order, not a compass bearing until the postcard's camera is determined. It differs from the Osaka Prefectural Library's 1913-album description in apparent left/right order, so both descriptions should remain separate pending original photo comparison. Ledger S030.

The page corrects our earlier search conclusion: an **online preview of a genuine program drawing does exist**, but no sufficiently sharp original scan for tracing was found. This resolves some topology for T2 while leaving exact facility coordinates, plan date and 1912 opening-day configuration unresolved. A library visit or authorized high-resolution copy would improve the eventual park reconstruction; tower exterior work can rely on the separate 1912/1914 photographic controls in the meantime.
