# P13 写真と模型の重ね合わせ（Claude、2026-09-30 13:12）

Codex の `repo/assets-src/shinsekai/tower-study/tower-study.glb`（11:13 版、**読むだけ**。書き換えていない）を、写真に合わせたカメラで Blender 4.5.10（画面なし・Workbench）で描いて写真に重ねた。写真はログイン不要の NDL の画像（`refs-claude\ndl-public\`、リポジトリに入れない）。

- 道具：`photomatch.py`（`blender -b --factory-startup --python photomatch.py -- <設定.json>`）。出力は `*_render.png`（模型だけ）、`*_overlay.png`（写真＋半透明の模型＋赤い輪郭＋十字）、`*_points.json`（模型の点と写真の目印の差、px と m）。緑の十字＝写真の目印、赤の十字＝模型の同じ点。
- 模型の寸法を試しに変える時は、設定の `transforms`（頂点の変形。元の GLB は変えない）。
- 軸は build-tower.py と同じ（X 東、Y 北、Z 上、m）。

## 1. 図版46（1921年、NDL 962657 コマ48、写真の切り出し x 560–1951, y 440–2300 の原寸 1391×1860 px）
カメラ（tower-study-review §13 の解の中央付近、屋上 15.15m を縮尺に）：焦点距離 1264 px、上向き 1.83°（角の塔の縁の傾き 0.6° から）、主点 (702, 1359.7)（地平線＝人の頭の行 1400。あおり＝レンズの上下のずらしを含む）、高さ 1.5m、真南向き、土台の北面から 45.3m。

### 1-2. 試しに寸法を変えた模型（`p46_variant_*`、元の GLB はそのまま）
変形：土台を前後に 7.7m ずつ深く（奥行き 26m、塔の中心は北面から 13m）、脚の幅と奥行きを屋上で 0.52 倍→高さ 55m（元の座標）で 1.0 倍に細める、塔の高さを 0.80 倍（頂 64m）、角の塔の屋上より上を 0.6 倍。カメラは土台の北面から同じ 45.3m。
| 目印 | 差（模型−写真） |
|---|---|
| 頂（64m） | 模型が 1.3m 低い → 写真の頂は **約65m** |
| 塔屋の上端 | 模型が 1.2m 高い → 写真 **約62m** |
| 展望台の下端 | 模型が 6.3m 高い → 写真 **約51m**（模型は展望台から上が短く、広すぎる） |
| 角の塔のドームの頂 | −0.2m（合う、約22m） |
| 脚の開き・胴の細り | 輪郭がほぼ重なる |
- アーチ（高さ・幅）と土台の正面の幅は、この変形では直していない（形を作り直す必要がある）。角の塔の頂の斜めの板は変形のゆがみ（本物の形ではない）。

## 2. 写真A（1914年『大阪独案内』NDL 952032 コマ95 右、`A_full.jpg` 890×1650 px、網点の印刷）
- 目印（px）：頂 (437.5, 55)、塔屋の上端 92.5、展望台の箱の上端 180・下端 295、屋上の床 (403, 945)、角の塔の外の縁 85 / 722（屋上の高さ）、角の塔のドームの頂 (145, 767)・(683, 793)、アーチの外周の頂 1020・内側の頂 1037。
- 土台の目印の 3D の位置は図版46 から（屋上 15.15m、正面の幅 28.2m、ドームの頂 22.1m、アーチの頂 10.9m）。カメラ（位置・向き・傾き・焦点距離・主点の行）を合わせ、塔の軸（北面から 13m 奥）の上で、写真の頂の行に写る高さを求めた（`towerfit-viewA.cjs`、`viewA-fixz.cjs`、`viewA-level.cjs`）。
- **カメラが決まりきらない**（目印がほぼ1枚の面の上にあるため、距離・高さ・焦点距離・上下の向きが互いに入れ替わる。残差はどれも 4〜7 px）。
| 仮定 | 頂 | 塔屋の上端 | 展望台の下端 |
|---|---|---|---|
| 何も縛らない（カメラ高さ 2〜28m、レンズ自由） | 53〜55m | 51〜54m | 42〜47m |
| カメラは水平（写真の縦の線がほぼ垂直）、焦点距離 700〜1800 px（画角 28〜65°） | **58〜66m** | 56〜64m | 46〜52m |

- 土台の奥行きを変えると（塔の中心が北面から 5.3〜20m）：頂 47〜62m（縛らない場合）。
- `c1815001`（北、345×537 px）は地面が見えないが、「屋上の手すり→塔屋の上端」と「角の塔の尖塔どうしの間」の比が写真A とほぼ同じ（1.60 と 1.51。図版46 は 1.21）。遠くから撮った写真ほど見かけの比が本当の比に近いので、A と c1815001 は**低め（55m 前後）**を示す。

## 3. まとめ（Codex への提案）
1. **75.76m はどちらの写真にも合わない**（図版46 では塔の中心が北面から 20m 以上奥、写真A では 30m 以上奥が必要）。
2. 2枚の写真の間で**食い違いが残る**：図版46（近く・低いカメラ）は 63〜68m、写真A・c1815001（遠いか高いカメラ）は 53〜66m。重なりは **およそ 58〜66m**。原因の候補：図版46 の地平線（人の頭）や奥のアーチの読み、写真A の印刷の修正（1914年の網点印刷は塔の輪郭を描き足すことがある）、土台の目印の高さ。どれも今の資料では決められない。
3. 高さに**関係なく直せる大きな形の違い**（M2 の形の審査の材料。どれも図版46 の写真から。1921年刊なので、1912年と違う所があり得る）：
   - 塔の脚の開き：屋上で約 11m（模型 22m）。胴は上に行くほど細く、展望台の下で最も細い。
   - 土台の奥行き：20〜30m（模型 10.65m）。塔の中心は土台の真ん中（前後対称の仮定）。
   - 角の塔：ドームの頂 約22m（模型 26.55m）。
   - アーチ：頂 約10.9m、幅 約20m（模型 13.5m、17m）。形は半円より平たい（足元 約2.9m から立ち上がる）。
   - 土台の正面の幅（角の塔の外の縁）：約28〜29.6m（模型 32.2m）。
   - 展望台から上：展望台の箱の下端から頂まで、写真では頂の高さの約 22%（65m なら約14m）。模型は約 8m で短い。
4. 全高はパラメータのまま（仮の値は重なりの真ん中の **約62m**、範囲 55〜68m）。屋上 15.15m は資料どおり固定。
