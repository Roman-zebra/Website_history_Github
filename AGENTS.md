# Repository instructions

## Shinsekai work

At the start of each Shinsekai session, read `docs/shinsekai/codex-state.json` and `docs/shinsekai/TASKS.md`, then continue from `next`. Read `docs/shinsekai/PLAN.md` for the project baseline and check `docs/shinsekai/research/` for new Claude handoffs. Keep the parent workspace's `PLAN.md` and `claude-out/` read-only.

Before asset or material revisions, follow `docs/shinsekai/research/vibe-modeling-method.md`: record a scoped brief, check official sources for the pinned tool versions, and compare one factor at a time with a fixed camera and light.
Read the applicable `docs/shinsekai/research/modeling-lessons.md` entry and the public-source constraints in `docs/shinsekai/research/kobataka-public-study.md`. Preserve numbered candidates and input hashes; inspect current outputs before retrying a timeout, and serialize mutations in each Blender scene.

Only Codex writes to this repository. Record questions and requests for Claude in `docs/shinsekai/requests-to-claude.md`. Preserve the map, search, and Gunkanjima behavior. Before pushing, pull with rebase; make small commits with one-line English messages.
