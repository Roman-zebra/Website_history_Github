# lab-3d：1962年の端島を、2枚の空中写真から立体にする（テスト）

トップの「06 テスト中」タブと `/lab/gunkanjima-3d`（noindex、サイトマップ外）が使う
`lab/gunkanjima-1962.jpg`・`lab/gunkanjima-1962-height.bin`・`lab/gunkanjima-1962.json` を作る手順。
サイトのビルドには含まれない（`scripts/build.cjs` は `scripts/` を公開しない）。

## 入力（リポジトリには入れない）

このフォルダの横に次の3つを置く。

- `photos/MKU628-C18-2.jpg`、`photos/MKU628-C18-3.jpg`
  国土地理院「地図・空中写真閲覧サービス」の400dpi画像。1962年5月30日撮影、カメラ RMK、焦点距離 152.67 mm。
  利用規約に同意して取得する。公開物には「国土地理院の空中写真を加工して作成」と出典を付ける。
- `tiles/<layer>_17_<x>_<y>.(png|jpg)`
  地理院タイル z17（`seamlessphoto`、`ort_old10`、`gazo1`）。x 112770〜112773、y 52953〜52958。
- `dem/dem5b_png_15_<x>_<y>.png`
  5mメッシュ標高タイル z15。x 28192〜28193、y 13238〜13239（無いタイルは404のままでよい）。

タイル番号は暗算しない。手で出して2回まちがえた（z17 の x、z15 の x）。

## 手順

1. `python mosaic.py` — タイルをレイヤーごとに1枚につなぐ。
2. `python stereo.py` — SIFT で照合し、USAC_MAGSAC で基礎行列、RANSAC ホモグラフィで写真2を写真3に重ね、
   エピポールの向きに回して StereoSGBM（左右一致チェックつき）。`out/rect_L.png` は写真3の 1024×1024 の切り出しで、そのままテクスチャになる。
3. `python georef.py` — 切り出しを地理院タイルに合わせ、1画素の大きさ（約0.805 m）と北の向きを出す。
4. `python calibrate.py` — 視差を高さに直す（鉛直写真の式 h = H(1 − P_sea/P)）。
   海面は写真では照合できないので、海面の視差 P_sea を、現在の5m標高の「開けた地面」の下包絡に平面で合わせる。
   外れ値の除去、細い針の除去（grey opening 7×7）、島の中だけの平滑化をしてから `out/web/` に書き出す。
5. `out/web/` の3ファイルを `lab/` にコピーする。

## 検算（2026-09-14）

- 地図の縮尺から出した飛行高度 1,950 m と、写真のふちに写る機上の高度計「ALT 1950」が一致。
- 東側に係留された浮き桟橋が海面 +2.5 m（水に浮く甲板として妥当）。
- 海面の合わせ方をオフセットだけにすると、同じ桟橋が +11 m になった。重ねに使った「平面」は500 pxで約29 m傾いていたので、傾きも合わせている（下包絡の残差 RMS 0.81 m、63ブロック）。
- 高さ：中央値 12.7 m、上位1% 45.6 m、最大 50.1 m（島の中央の岩の尾根）。
- 照合できず周りの値で埋めた点：16.3%。

## 限界

- 写真2枚だけのステレオ。場所によって高さが数メートルずれる。
- 上から奥が見えない狭い路地は埋まり、壁は斜面になる。煙突のような細いものは消している。
- 海面の基準は現在の標高データで決めている。1962年当時の測量値ではない。
