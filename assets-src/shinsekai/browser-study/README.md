# Local browser renderer study

This is a **non-public T4 technology study**, separate from the published site. It loads the T3 `tower-study.glb` and tests three.js r186 `WebGPURenderer` with its WebGL 2 fallback, orbit controls, resize, and provisional day/dusk/night lighting. It does not claim to show final 1912 geometry, colour, location or illumination. The source GLB's 75.76 m default is one adjustable scenario, while only its 50-shaku roof level has near-opening documentation.

From the repository root, run `node scripts/serve-shinsekai-study.cjs` and open `http://127.0.0.1:18765/assets-src/shinsekai/browser-study/index.html`. Add `?webgl` to force the WebGL 2 backend for comparison. This dedicated origin avoids the main site's development service worker on port 8765, which Claude found was replacing the study with the home page. If an overridden port has the same problem, choose a fresh `JTA_STUDY_PORT`. The server binds to loopback and serves only this study, its GLB and the pinned three.js vendor files; repository metadata and other sources are denied. The Workers build copies `vendor/` but excludes `assets-src/`, so the viewer and study GLB are not published or linked by the site.

Rendering now runs on demand, including orbit damping and resize, and pauses when the tab is hidden. The frame count should stop increasing after a drag settles. **Measure 5 seconds** warms up for one second, then draws the static model continuously for five seconds. It reports display-frame intervals and canvas resolution, not GPU execution times or a production-scene performance result. Hiding the tab cancels that measurement. Try both backends, all three lighting buttons, drag/zoom, resize, idle and hidden-tab behaviour before accepting an iteration.

Claude handoff 53 confirmed the demand-rendering revision on both backends, idle counts at rest, and approximately 100 Hz static cadence at 958×862 on the GTX 1660 SUPER. WebGPU lighting/orbit/resize passed; fuller WebGL interaction and mid-measurement hiding remain open. His hidden-start benchmark bug is now guarded and has a 10-second watchdog; that fix and the new collapsible small-viewport panel await follow-up. Codex's Computer Use tool stopped on URL verification, so the real-GPU observations are Claude's rather than an independent Codex browser check.

The vendor files under `vendor/three-r186/` come from the official three.js 0.186.0 npm package. `PROVENANCE.json` records the tarball and individual file hashes; `LICENSE` preserves the MIT notice. The browser imports only the WebGPU/core builds, GLTFLoader, OrbitControls and their two utilities. Do not add historical scene props until the plan and rights review supports them.
