These seven original JPEGs were downloaded from the [Osaka Municipal Library Digital Archive](https://image.oml.city.osaka.lg.jp/da/top) on 2026-09-30 using `node scripts/fetch-shinsekai-oml.cjs`. Each individual record states `申請不要・二次利用可`, `CC0（CC0 1.0 全世界 パブリック・ドメイン提供）`, and `オープンデータ`. The archive's [open data policy](https://www.oml.city.osaka.lg.jp/page/1633.html) applies. Credit the library and link to the item record when displayed, even though CC0 does not require attribution.
